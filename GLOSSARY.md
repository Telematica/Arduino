# Glossary

* Nominal Voltage
* SMD (Surface-Mount Device)
* SPI (Serial Peripheral Interface) is a short-distance, 4-wire synchronous communication protocol used in microcontrollers and sensors.
* UART (Universal asynchronous receiver-transmitter)
* NO (Normally Open)
* NC (Normally Closed)
* LED (Light Emission Diode)

* SPDT (Single Pole, Double Throw) configuration with Normally Open and Normally Closed contacts.

## Components

* Breadboard
* Capacitor
* Relay
* Resistor
